# 🎯 Face Recognition Attendance System

An AI-powered Face Recognition Attendance System built using **Python**, **OpenCV**, and **Tkinter**. The system detects and recognizes registered faces and automatically marks attendance with date and time.

---

## 🚀 Features

- 👤 Register new students
- 📸 Capture face images
- 🧠 Train face recognition model
- ✅ Automatic attendance marking
- 📅 Attendance stored with date
- 🖥️ Simple Tkinter GUI
- 💾 Local database support

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Tkinter
- NumPy
- JSON
- Haar Cascade Classifier

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/himanshi282/FaceRecognitionAttendance.git
```

Move into project

```bash
cd FaceRecognitionAttendance
```

Install dependencies

```bash
pip install opencv-python numpy pillow
```

---

## ▶️ Run Project

```bash
python app.py
```
